# Knowledge

Модуль принадлежит направлению data. Схема PostgreSQL находится в `schema.sql`, инструкции загрузки — в [описании импорта](../../../scripts/ingest/README.md).

Backend передаёт подключение `*sql.DB` и каталог `data/synthetic/resources.json` в `NewSearcher`. Поиск принимает `Actor` из доверенной серверной сессии. SQL фильтрует команду и роль перед ранжированием и ограничением выдачи. Алиасы учебных ресурсов расширяются из каталога команды пользователя. Публичные названия вроде «Графана» и «техдеп» распознаются для всех пользователей. Поиск сопоставляет алиасы по границам слов. Результат содержит идентификаторы и версии источников.

Модуль отделён от HTTP-обработчика. Backend подключает его к сессии. Для прямого открытия источника обработчик вызывает `GetDocument(ctx, actor, documentID)`. Для чужого или отсутствующего документа возвращается `ErrDocumentNotFound`, который API преобразует в 404. AI использует возвращённые фрагменты как данные для ответа.
