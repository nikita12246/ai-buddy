# Корпус и поиск

- D1. Реестр включает восемь ссылок из кейса и разделяет загрузку, пригодность для индекса и справочные материалы.
- D2. Импорт читает локальные снимки чек-листа, выбранных Markdown и HTML. Фрагменты сохраняют версию, источник и локатор. Снимки и результат обработки лежат в каталогах, исключённых из Git.
- D3. Учебные регламенты двух вымышленных команд используют общий каталог ресурсов. Каждый фрагмент содержит явную маркировку, идентификатор команды и список ролей.
- D4. Поиск применяет серверный контекст команды и роли до ранжирования и ограничения результата. Алиасы ресурсов принадлежат своей команде. Возвращаются проверяемые идентификаторы источников.
- D5/D6. Эталонный набор содержит 30 случаев. Для каждого зафиксированы ожидаемое действие, факты и допустимые источники. Прогон на модели и отчёт собираются совместно с направлением AI.

## Приёмка

1. Импортировать обе вкладки и сохранить адрес каждой строки.
2. Одинаковый вопрос о доступе к GitLab у Atlas и Orbit возвращает правила соответствующей команды.
3. При поиске стажёр не видит документы чужой команды даже при точном запросе.
4. При отсутствии информации выдача пуста или недостаточна для ответа. AI проверяется по эталону и не придумывает правило.
