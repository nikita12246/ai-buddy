# Учебные данные

- `policies.jsonl` — 12 явно синтетических инструкций Atlas и Orbit с идентификаторами, версиями и правами.
- `resources.json` — 8 учебных ресурсов с идентификаторами инструментов, командами и алиасами для поиска.

Идентификаторы фрагментов используются в эталонном наборе. При правке фактов обновляйте соответствующие проверки и версию источника. Для учебного источника `source_url` равен `null`. Его можно открыть в приложении по `document_id` после проверки прав.
