В Bitbucket Data Center для доступа Git по SSH можно добавить публичную часть личной пары ключей в настройки своего профиля. Приватная часть ключа остаётся на вашем устройстве. Для подключения берут SSH-адрес клонирования из интерфейса репозитория. Маршрут применим, когда администратор включил SSH и у пользователя есть право читать репозиторий. Конфигурацию Stash в своей организации уточните у наставника.
