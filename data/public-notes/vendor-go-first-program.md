Создай отдельную папку для упражнения. В ней выполни `go mod init example/hello`, чтобы создать go.mod. Добавь файл hello.go с `package main` и функцией main. Для запуска из этой папки выполни `go run .`. Это пример из учебника Go для новой программы. У существующего проекта могут быть свои команды запуска.
