Контекст kubeconfig объединяет кластер, пользователя и пространство имён (namespace). Kubectl по умолчанию обращается к кластеру с параметрами текущего контекста. Чтобы выбрать другой из уже настроенных контекстов, используй `kubectl config use-context <имя>`. Имя рабочего контекста и доступы уточняй у команды.
