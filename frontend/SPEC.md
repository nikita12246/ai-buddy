# Frontend — текущее состояние сценариев

Документ фиксирует реализованное поведение frontend. Выполнение серверных критериев из `../specs/README.md` этим не подтверждается.

| Сценарий | Реализован | Ограничения |
| --- | --- | --- |
| F1: диалог и ссылки на документы | Да | Поиск по PostgreSQL и проверка доступа через backend |
| F2: ввод, ожидание и ошибки | Да | Повтор использует исходный идентификатор сообщения |
| F3: форма и подтверждение заявки | Да, учебный сервис | Черновик хранится и версионируется на backend |
| F4: статусы и восстановление после перезагрузки | Да | Клиент обновляет статус из API и восстанавливает текущий диалог после входа в той же вкладке |
| F5: проверки | Да | Тесты frontend и сквозная проверка HTTP через прокси интерфейса |
| F6: пользовательские прогоны | Нет | Нужна ручная проверка командой |
| UI-01 из общей SDD | Да | История загружается с backend |
| ACCESS-01…04, ACL-01…02, AI-01…02 | Учебная интеграция | Живой прогон требует настроенного провайдера |

В демонстрационном режиме заявки обрабатывает учебный сервис. База содержит синтетические политики и карточки по публичным источникам.
